# 🚀 Smart Complaint Management System (SCMS)

A full-stack **Complaint Management System** designed to handle citizen complaints efficiently with a strong focus on **PostgreSQL database design, SQL optimization, and backend architecture**.

---

## 📌 Overview

The Smart Complaint Management System (SCMS) is a digital platform that allows:

### 👤 Citizens
- Submit complaints
- Track complaint status
- Upload evidence (images/documents)
- Receive notifications

### 🧑‍💼 Officers
- View assigned complaints
- Update complaint status
- Upload action proof

### 🏢 Admins
- Assign complaints to officers
- Monitor system performance
- Manage users and departments

---

## 🛠️ Tech Stack

### 🔹 Backend
- FastAPI (Python)
- REST APIs
- JWT Authentication

### 🔹 Database (Core Focus 🔥)
- PostgreSQL
- Raw SQL (No ORM)
- Advanced SQL Features:
  - Views
  - Triggers
  - Functions
  - Indexing
  - Constraints
  - Audit Logging

### 🔹 Frontend
- React / Streamlit (UI Layer)

---

## 🧠 Database Highlights (Key Strength)

This project strongly emphasizes **database engineering and SQL expertise**:

- ✅ Normalized relational schema
- ✅ Strong foreign key relationships
- ✅ Optimized indexing strategy
- ✅ Role-based data modeling
- ✅ Audit logging using triggers
- ✅ Automated workflows using database triggers
- ✅ Analytical views for dashboards
- ✅ Window functions (for advanced analytics)

## 🚀 How to Run the Project

### 1️⃣ Clone the Repository

```
git clone https://github.com/your-username/Smart-Complaint-System.git
cd Smart-Complaint-System
```

---

### 2️⃣ Setup PostgreSQL Database

* Create database:

```
CREATE DATABASE scms;
```

* Run SQL files in order:

```
schema.sql
indexes.sql
views.sql
functions.sql
triggers.sql
seed.sql
```

---

### 3️⃣ Run Backend (FastAPI)

```
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

---

### 4️⃣ Run Frontend

```
cd frontend
npm install
npm start
```
