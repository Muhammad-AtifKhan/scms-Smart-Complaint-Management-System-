# 🏛️ Smart Complaint Management System

## 📋 Overview
A production-ready complaint management system with **enterprise-grade PostgreSQL database design**. This project demonstrates advanced SQL capabilities including complex relationships, triggers, views, and performance optimization.

## 🎯 Key Highlights
- ✅ **10+ Tables** with proper relationships
- ✅ **8+ Views** for analytics and data abstraction
- ✅ **6+ Triggers** for automation
- ✅ **6+ Functions** for business logic
- ✅ **15+ Indexes** for performance
- ✅ **Audit logging** system
- ✅ **Real-time notifications** system

## 🗄️ Database Schema

### Core Tables
| Table | Description |
|-------|-------------|
| users | Citizen, officer, admin management |
| departments | Government departments |
| categories | Complaint categories per department |
| complaints | Main complaints table |
| complaint_assignments | Officer assignments tracking |
| complaint_history | Audit trail of all changes |
| complaint_files | Evidence and document storage |
| notifications | User notification system |
